# Сынок PRO — канал обновлений APK

Публичный репозиторий **только для готовых установочных файлов APK и манифеста обновлений** приложения «Сынок PRO / Титан».

## Правила публикации

- Основной исходный код приложения остаётся в **закрытом** репозитории.
- Здесь не хранятся исходники, пароли, токены, приватные ключи подписи, файлы `.keystore`, резервные копии ключей и иные секреты.
- APK и **рабочий** `manifest.txt` публикуются **только после отдельного явного утверждения владельцем конкретной сборки**.
- Манифест формируется из фактически собранного и проверенного APK штатным скриптом `tools/release_manifest.py` в закрытом проекте; он содержит версию, SHA-256 APK, SHA-256 сертификата подписи, коммит и подтверждение владельца.
- Телефон получает `manifest.txt` по HTTPS и скачивает готовый APK из GitHub Releases; подпись обновления проверяется перед установкой.
- Не публиковать здесь тестовые APK как стабильные обновления и не подменять существующие версии.

## Состояние канала

Канал подготовлен, **релиз и рабочий `manifest.txt` ещё не опубликованы**. Файл `manifest.example.txt` — нерабочий шаблон, его нельзя переименовывать в `manifest.txt` без настоящего утверждённого APK и сверки всех полей.

После публикации рабочий манифест будет доступен по адресу:
`https://raw.githubusercontent.com/razvedka60834-bit/synok-pro-updates/main/manifest.txt`

**Важно:** любой опубликованный здесь APK будет публично доступен для скачивания; это не даёт доступа к приватным исходникам или ключам.

Инструкция по выпуску и проверке: `docs/UPDATE_CHANNEL.md` в закрытом репозитории Титана.
